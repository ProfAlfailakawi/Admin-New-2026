# 🍳 مطبخ التراث الكويتي — النظام المحاسبي المتكامل v2.0 Pro

نظام محاسبي متطور ومخصص لإدارة مطبخ التراث الكويتي، مصمم ليكون سهل الاستخدام واحترافي في عرض البيانات والتحليلات.

---

## 📋 المميزات الرئيسية

### 🏠 لوحة التحكم الذكية
- **الإنفوجرافيك المالي**: عرض تدفق الإيرادات والأرباح بشكل بصري (مبيعات، توصيل، رسوم KNet).
- **مؤشرات الأداء**: متابعة المبيعات، التكاليف، وصافي الربح بوضوح.
- **رسومات بيانية**: تحليل المبيعات والأقسام الأكثر طلباً.

### 🧾 نظام الفواتير المتطور
- **اختيار سريع**: grid تفاعلي لاختيار المنتجات بلمسة واحدة.
- **آلية ذكية**: تعبئة رقم الهاتف تلقائياً عند اختيار العميل.
- **الخصوصية**: إخفاء هامش الربح في الفاتورة (متاح فقط في التقارير الداخلية).
- **الدفع**: مخصص لـ K-Net فقط للعملاء لضمان التنظيم.

### 🤝 إدارة الموردين والمصروفات
- **طرق دفع متعددة**: (رابط، K-Net، تحويل بنكي) للموردين والمصاريف.
- **تصنيفات المصاريف**: متابعة دقيقة لكل فلس يتم صرفه.

### 📊 التقارير والذكاء الاصطناعي
- **تقارير مجمعة**: نافذة واحدة لجميع البيانات (الفواتير، الأرباح، المصاريف).
- **تصدير البيانات**: دعم PDF و Excel.
- **المساعد الذكي AI**: مستشارك المالي المدمج (Gemini) لتحليل البيانات وتقديم نصائح للنمو والتطوير.

---

## 🛠️ تفاصيل تقنية

### الهيكل التنظيمي
- **/frontend**: تطبيق React مع Tailwind CSS و Recharts.
- **/backend**: خادم Node.js مع Express.
- **database.sql**: مخطط قاعدة البيانات للأنظمة المستقبلية.

### الألوان المستخدمة
- **أحمر (#C8102E)**: اللون الأساسي (مستوحى من علم الكويت).
- **أخضر (#2E6B35)**: التوازن والأرباح.
- **ذهبي (#D4A84B)**: الفخامة والتراث.

## 🚀 كيفية التشغيل

1. تأكد من وجود `GEMINI_API_KEY` في ملف `.env`.
2. قم بتشغيل الأمر:
   ```bash
   npm run dev
   ```
3. افتح الرابط المباشر.
