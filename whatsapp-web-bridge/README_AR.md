# جسر واتساب التراث — تشغيل الماك

هذا المجلد مستقل عن برنامج التراث. لا يحتوي كود الدفع أو الإشعارات، ولا يشغّل متصفحاً داخل Cloud Run. وظيفته الوحيدة ربط جهاز واتساب المرتبط بالسيرفر عبر قناة داخلية محمية بسر.

## قبل التشغيل

1. ارفع ملف `server.ts` المعدل إلى خدمة الأدمن وأعد نشرها.
2. عرّف في خدمة Cloud Run:
   - `WHATSAPP_TRANSPORT=web_bridge`
   - `WHATSAPP_BRIDGE_SECRET=<سر عشوائي طويل>`
3. انسخ `.env.example` إلى `.env` وضع رابط الأدمن ونفس السر بالضبط.

## التشغيل على الماك

1. افتح `install-mac.command` مرة واحدة.
2. بعد التثبيت افتح Terminal داخل المجلد وشغّل `npm run check`.
3. افتح `start-mac.command`.
4. في أول مرة سيظهر QR. من الهاتف: واتساب > الإعدادات > الأجهزة المرتبطة > ربط جهاز.
5. عندما تظهر عبارة `بوت التراث جاهز` أرسل رسالة إلى الرقم من هاتف آخر.

## إيقاف آمن

داخل نافذة التشغيل اضغط `Control + C`. الجلسة تبقى محفوظة داخل `.session` ولن تحتاج QR كل مرة.

## تشغيل احترافي تلقائي

بعد نجاح التجربة، افتح `install-autostart-mac.command`. سيعمل البوت تلقائياً عند دخولك للماك، وينتظر توفر الإنترنت، ويعيد تشغيل نفسه عند الانقطاع، ويستخدم `caffeinate` لمنع نوم الماك أثناء عمله فقط. للإلغاء استخدم `uninstall-autostart-mac.command`.

السجلات المحلية تحفظ داخل `logs/` مع تدوير حجمي تلقائي عبر `service-runner.mjs`، ولا تطبع السر أو نصوص رسائل العملاء.

## مهم

- لا تحذف مجلد `.session` ولا ترسله لأي شخص؛ فهو يحتوي مفاتيح الجهاز المرتبط.
- لا تشغّل نسختين من الجسر بنفس الرقم والجلسة في الوقت نفسه.
- هذا الربط يستخدم WhatsApp Web بطريقة غير رسمية؛ قد يتأثر بتحديثات واتساب أو يتعرض الرقم للتقييد. يظل Cloud API الرسمي هو الخيار الإنتاجي الأكثر أماناً.
