## الملفات المعدّلة (2): server.ts · src/components/WhatsAppSupportInbox.tsx

### 1) 🔒 ثغرة أمنية حرجة (سبب تسرّب رقمك على الأرجح)
نقاط `/api/whatsapp/*` كانت **مكشوفة للعامة بالكامل** (مؤكّد: 200 بدون أي صلاحية):
أي أحد يقرأ كل محادثات العملاء (أرقام + نصوص)، ويرسل واتساب باسمك، ويعدّل قواعدك.
**الإصلاح:** بوابة تتحقق من Firebase ID token + نفس هويات الأدمن/الشريك في firestore.rules.
الويبهوك والـbridge مستثنيان (لهم تحققهم الخاص). الواجهة صارت ترسل التوكن في كل نداء.

### 2) 🔗 رابط التتبع كان يوجّه العميل لدومين الأدمن
`ALTURATH_TRACK_BASE_URL` كان يرجع احتياطياً لـADMIN. صار CUSTOMER → alturathkw.shop/track

### 3) 🤖 البوت كان يكرر نفس الرسالة الطويلة
"السلام عليكم" ثم "كيف الحال" = نفس الرد الطويل مرتين.
- منع تكرار: ما يرسل رداً مطابقاً للرد السابق (يستخدم lastOutboundText الموجود أصلاً).
- قاعدة دردشة: "كيف الحال/شلونك" يلقى رداً قصيراً دافئاً.

### 4) 📋 قواعد الرد التلقائي (كانت صفر — لهذا ما شفت شي)
16 قاعدة + زر "✨ القواعد الجاهزة" (ما يدهس أي قاعدة تعدّلها).
**كلها من بياناتك الحقيقية:** المنيو والأسعار عبر `action:"products"` (منتجاتك وأسعارك الفعلية).
وأي شي ما نقدر نتحقق منه (حلال، مكونات، الفروع) → **يحوّل لموظف** بدل التخمين.

### 5) 🐛 ترتيب الرسائل
كانت تجلب "أقدم 200" فتختفي الجديدة بالمحادثات الطويلة. صارت أحدث 200.
