# إصلاح: القائمة السفلية في «المساعد الذكي» ما كانت ظاهرة

## السبب الجذري
هيكل شاشة المساعد `.ai-executive-assistant-shell` كان ياخذ ارتفاع ثابت
محسوب بالغلط: `height: calc(100dvh - 96px)`.

لكن فوق الشاشة و حولها في ارتفاع أكبر من 96px:
- هيدر ثابت (sticky header): 80px بالديسكتوب / 48px بالموبايل.
- padding داخل `<main>`: 48px بالديسكتوب (lg:p-6) / 24px بالموبايل (p-3).

يعني المساحة الفعلية المتاحة = تقريباً `100dvh - 128px` بالديسكتوب،
بينما الهيكل يطلب `100dvh - 96px` → أطول بحوالي 32px.
الزيادة تطلع تحت حدود `<main>`، و لأن `.ai-executive-console` عنده
`overflow:hidden` انقصّ أسفل الصندوق، فاختفت قائمة اقتراحات الأسفل
(ai-suggestion-grid) و صندوق الإدخال.

## الحل
بدّلنا حساب الـ viewport الهشّ بجعل الهيكل يملأ الحاوية الأم مباشرة:
`height:100%; min-height:0;` — فيتطابق تماماً مع المساحة المتاحة مهما
تغيّر ارتفاع الهيدر أو الـ padding، و يبقى شريط الإدخال و القائمة ظاهرين.

## الملف المعدّل (الوحيد)
- `src/index.css`
  - القاعدة الأساسية لـ `.ai-executive-assistant-shell`
  - قاعدة الـ override (max-width:1280px)
  - قاعدة الموبايل داخل `@media(max-width:760px)`

كلها: `calc(100dvh - Npx)` → `height:100%; min-height:0`.
