السبب الجذري:
محرك البوت ومركز المحادثات موجودان في البرنامج، لكنهما كانا يرسلان حصراً عبر Meta Cloud API. لم توجد قناة تربط جهاز WhatsApp Web بالبوت الحالي.

ما تم:
- إضافة Web Bridge معزول ومغلق بسر.
- طابور إرسال داخل Firestore مع lease وإقرار إرسال وإعادة محاولة.
- منع تكرار الرسائل الواردة والصادرة.
- استمرار الرد اليدوي من مركز واتساب الذكي.
- حفظ جلسة واتساب محلياً وتشغيل تلقائي اختياري على macOS.
- منع البحث عن طلب عميل آخر بمجرد كتابة رقم هاتفه.
- الوضع الافتراضي يبقى Cloud API؛ لا يتفعّل الجسر إلا عبر WHATSAPP_TRANSPORT=web_bridge.
